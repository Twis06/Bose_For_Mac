A tiny native macOS menu bar controller for Bose QC Ultra headphones.

- Compact vertical battery indicator, with exact charge in the menu and tooltip.
- Quiet, Aware, Immersion and configured custom modes read from your headphones.
- Three-band EQ with six attributed presets, complete readback and undo.
- Native light/dark appearance, optional launch at login, no Dock icon or account.
- Universal app for Apple silicon and Intel; macOS 13 or later.

Download the DMG and drag Bose Bar to Applications, or use the checksum-verifying installer in the README. The ZIP is provided for manual/terminal installation. SHA256SUMS covers both downloads.

This independent community build is ad-hoc signed, not Apple-notarized. If macOS blocks opening it, use System Settings → Privacy & Security → Open Anyway after reviewing the source and release. Do not disable Gatekeeper.

Hardware verified: original QC Ultra, firmware 1.6.7. QC Ultra 2 capability handling is implemented but not hardware-verified. The original Ultra uses its listening modes for noise control; unsupported Ultra 2-only controls stay hidden. EQ recommendations are listening preferences, not calibration profiles.
